# Flappy Arcade

Juego arcade estilo Flappy Bird hecho con HTML5 Canvas y JavaScript vanilla, sin dependencias ni build step.

## Jugar

- Online: https://amozotg349.github.io/flappy-arcade/
- En local: abre `index.html` en el navegador.

## Controles

- Ratón, toque, `Espacio` o `Flecha arriba`: volar.
- Supera los tubos para sumar puntos; el récord se guarda en `localStorage`.
- Medallas: bronce 10, plata 20, oro 30, diamante 40.

## Estructura

- `index.html` — canvas, HUD y overlays
- `css/style.css` — estilos y responsive
- `js/game.js` — lógica del juego
